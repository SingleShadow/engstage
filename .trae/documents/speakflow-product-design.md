# EngStage — 英语跟练助手 产品设计方案

## 一、产品概述

| 项目 | 说明 |
|------|------|
| **产品名称** | SpeakFlow — 英语跟练助手 |
| **产品形态** | Web 应用（响应式，支持移动端） |
| **核心定位** | 基于真实对话场景的沉浸式英语跟练工具 |
| **目标用户** | 英语初/中级学习者、备考雅思托福口语考生、希望提升日常英语交流能力的成年人 |

## 三、核心功能设计

### 3.1 打字跟练模式（Typing Mode）

**交互流程：**
1. 场景中角色A说出台词 → 字幕显示英文 + 中文翻译
2. 用户在输入框中打字回复（需与标准答案匹配）
3. 提交后即时反馈：
   - ✅ 完全匹配 → 绿色提示 + 播放发音
   - ⚠️ 接近匹配 → 黄色提示 + 高亮差异词 + 播放发音
   - ❌ 不匹配 → 红色提示 + 显示标准答案 + 可重试
4. 通过后角色B播放发音动画 + 语音
5. 进入下一轮对话

**辅助功能：**
| 功能 | 说明 |
|------|------|
| 💡 提示 | 显示首字母 / 关键词提示（消耗提示次数） |
| ⏭️ 跳过 | 跳过当前句（记录为"跳过"，可在复习时重做） |
| 🔍 差异对比 | 输入后实时高亮与标准答案的差异 |
| 🔊 语速调节 | 播放标准发音时可选 0.75x / 1.0x / 1.25x |
| 📖 语法注释 | 句子下方显示关键语法点说明 |

### 3.2 语音跟练模式（Speaking Mode）

**交互流程：**
1. 场景中角色A说出台词 → 字幕显示
2. 用户看到需要跟读的句子
3. 点击麦克风开始录音（3秒倒计时）
4. 语音识别后给出**发音评分**：
   - 音准（Accuracy）：发音是否准确
   - 语速（Fluency）：是否流畅无卡顿
   - 语调（Intonation）：语调起伏是否自然
5. 综合评分 ≥ 70分 → 通过 → 角色播放标准发音
6. < 70分 → 建议重试 + 显示薄弱音标

**辅助功能：**
| 功能 | 说明 |
|------|------|
| 🎙️ 重新录制 | 不满意可无限重录 |
| 🔊 播放原声 | 对比标准发音找差距 |
| 🐢 慢速播放 | 0.75x 慢速播放标准发音 |
| 📊 波形对比 | 可视化显示用户发音与标准发音的波形差异 |

### 3.3 分支对话系统

**亮点功能：每个场景有 2-3 个分支走向**

示例（咖啡店场景）：
```
标准对话：
  店员: "What would you like to order?"
  → 顾客: "I'd like a latte, please."

分支A（加购）：
  → 顾客: "A latte, and also a muffin, please."
  → 店员: "Would you like the blueberry or chocolate muffin?"
  → 顾客: "Blueberry, please."

分支B（特殊要求）：
  → 顾客: "Can I get a latte with oat milk?"
  → 店员: "Of course! That's no problem."
```

- 用户的不同回复会触发不同的后续对话
- 完成一个场景后可查看"分支地图"，看到自己走过的路径
- 鼓励用户多次练习同一场景，探索不同分支

### 3.4 沉浸式场景音效

| 场景 | 背景音效 |
|------|---------|
| 咖啡店 | 咖啡机声、轻音乐、杯盘碰撞声 |
| 餐厅 | 背景人声、餐具声 |
| 超市 | 购物车滚动声、扫描仪"嘀"声 |
| 打车 | 引擎声、转向灯声 |
| 酒店 | 大堂轻音乐 |
| 面试 | 安静办公室氛围 |
| 医院 | 呼叫器、仪器声 |
| 派对 | 音乐、笑声、碰杯声 |

- 音量可调节，支持关闭
- 帮助用户沉浸到场景中，模拟真实环境

### 3.5 游戏化系统

#### 金币 & 成就
| 成就 | 条件 | 奖励 |
|------|------|------|
| 🥇 初次开口 | 完成第一个场景 | 50金币 |
| 🗣️ 话唠 | 累计练习100句 | 100金币 |
| ⭐ 完美发音 | 单场景发音评分全 ≥ 90 | 150金币 |
| 🏃 连续打卡 | 连续7天练习 | 200金币 |
| 🗺️ 场景达人 | 完成所有场景 | 500金币 |
| 🔀 探索者 | 在分支对话中走遍所有分支 | 300金币 |

#### 排行榜（本地）
- 本周练习时长排行
- 发音评分排行
- 场景完成度排行

#### 等级系统
```
Lv.1 🌱 英语新手     (0-500分)
Lv.2 🌿 初级学者     (500-1500分)
Lv.3 🌳 进阶达人     (1500-3000分)
Lv.4 🏔️ 口语高手     (3000-5000分)
Lv.5 🌟 英语大师     (5000分以上)
```

### 3.6 每日挑战

| 挑战类型 | 说明 |
|----------|------|
| 📅 每日一句 | 每天推送一个实用句子，跟读打卡 |
| 🎯 每日场景 | 推荐一个场景，完成后获得双倍金币 |
| ⏱️ 限时挑战 | 60秒内尽可能多地说出正确句子 |
| 🧩 听写挑战 | 播放一段对话，用户听写关键句子 |

### 3.7 AI 智能纠错

- 打字模式下：识别语法错误，给出修改建议
  - 例："I goes to school" → "建议改为 'I go to school'（主语 I 用原形）"
- 语音模式下：识别发音偏差，给出针对性建议
  - 例："注意 'th' 音需要舌尖放在上下齿之间"
- 每次练习后生成"语法/发音小贴士"卡片

### 3.8 学习数据面板

#### 统计指标
| 指标 | 说明 |
|------|------|
| 完成场景数 | 已完成的对话场景总数 / 总场景数 |
| 平均发音分 | 语音模式下的平均评分 |
| 打卡天数 | 连续练习天数 + 最长连续记录 |
| 薄弱音标 | 自动统计发音偏低的音标 |
| 练习时长 | 今日/本周/本月累计时长 |
| 错题本 | 自动收录答错的句子，可一键复习 |

#### 趋势图表
- 每日练习时长折线图
- 发音评分变化趋势
- 各场景完成度雷达图

## 七、验证方式

1. 启动开发服务器，浏览器打开应用
2. 首页场景选择 → 点击进入场景详情 → 选择模式开始跟练
3. 打字模式：输入正确/错误/接近的答案，验证反馈机制
4. 语音模式：录音、评分、重录，验证语音识别功能
5. 分支对话：选择不同回复，验证后续对话变化
6. 数据面板：完成几个场景后，验证统计数据正确
7. 响应式：调整浏览器窗口大小，验证移动端适配
